# 一维势场中的粒子
## 7个定理，前四个会证明

### 定理1
若$\psi(x)$ 是能量本征方程的一个解，对应能量本征值为 $E$，则 $\psi^*(x)$ 也是方程的一个解，对应能量也是$E$。

**Proof**：取复共轭得

$$\left(-\frac{\hbar^2}{2m}\frac{d^2}{dx^2} + V(x)\right)\psi^*(x) = E\psi^*(x)$$

(Q.E.D.)

### 定理2
对应于能量的某个本征值$E$，总可以找到方程(3)的一组实解，凡是属于 $E$ 的任何解，均可表示为这组实解的线性叠加。

**Proof**：设 $\psi(x)$ 是能量本征方程的一个解，如果是实解，就放到实解的集合中；如果是复解，则 $\psi^*(x)$ 也是方程的解。由微分方程的叠加原理可知
$$\varphi(x) = \psi(x) + \psi^*(x), \quad \chi(x) = -i\left(\psi(x) - \psi^*(x)\right)$$

也是方程的解：
$$\varphi(x) = \psi + \psi^*, \quad \chi(x) = -i(\psi - \psi^*)$$

都是方程的解，且为实解。则：
$$\psi = \frac{1}{2}(\varphi + i\chi), \quad \psi^* = \frac{1}{2}(\varphi - i\chi)$$

(Q.E.D.)

### 定理3
若$V(x)$ 具有空间反射不变性，即$V(x) = V(-x)$，如 $\psi(x)$ 是能量本征方程的对应$E$ 的解，则 $\psi(-x)$ 也是解，对应$E$。

**Proof**：当 $x \to -x$ 时，

$$\frac{d^2}{d(-x)^2} = \frac{d^2}{dx^2}, \quad V(-x) = V(x)$$

$$\Rightarrow \left(-\frac{\hbar^2}{2m}\frac{d^2}{dx^2} + V(x)\right)\psi(-x) = E\psi(-x)$$

(Q.E.D.)

### 定理4
若$V(-x) = V(x)$，则对应于任何一个能量本征值$E$，总可以找到能量本征方程的一组解（每个解都有确定的宇称），而属于能量本征值$E$ 的任何解，都可以用它们来展开。

**Proof**：按定理3，$\psi(-x)$ 也是方程的解，如没有确定宇称，可构造：
$$f(x) = \psi(x) + \psi(-x), \quad g(x) = \psi(x) - \psi(-x)$$

$$\Rightarrow f(x) = f(-x), \quad g(x) = -g(-x)$$

$$\Rightarrow \psi(x) = \frac{1}{2}\left(f(x) + g(x)\right), \quad \psi(-x) = \frac{1}{2}\left(f(x) - g(x)\right)$$

(Q.E.D.)

### 定理7（判断）
粒子在规则势场中运动（$V(x)$），如存在束缚态，则必定不简并。

**束缚态**：粒子被限制在有限空间内运动的状态，波函数在无穷远趋于零。能量通常取离散值。
## 一维无限深方势阱
### 情况一：势场不对称分布（会推）

<figure> 
   <img src="/img/picture/screenshot001.png" alt="一维无限深方势阱（不对称分布）" style="max-width: 100%;"> 
   <figcaption>一维无限深方势阱（不对称分布）</figcaption> 
 </figure>

$$V(x) = 
\begin{cases}
0, & 0 < x < a, \\
\infty, & x < 0,\ x > a.
\end{cases}$$

能量本征方程：
$$-\frac{\hbar^2}{2m}\frac{d^2}{dx^2}\psi + 2mV\psi = E\psi $$

$$\Rightarrow \frac{d^2}{dx^2}\psi + \frac{2mE}{\hbar^2}\psi = 0.$$

解为

$$\psi = A\sin\left(\frac{n\pi}{a}x\right),\quad A = \sqrt{\frac{2}{a}}.$$

$$\Rightarrow
\begin{cases}
\psi(x) = \sqrt{\dfrac{2}{a}}\sin\left(\dfrac{n\pi}{a}x\right), & x\in(0,a), \\
\psi(x) = 0, & x\notin(0,a).
\end{cases}$$

**能量本征值**

$$E = E_n = \dfrac{\hbar^2\pi^2n^2}{2ma^2}.$$

### $E > V(x)$ 区域
能量本征方程：
$$\psi'' + \frac{2m}{\hbar^2}(E - V(x))\psi = 0$$

令
$$k^2 = \frac{2m(E - V(x))}{\hbar^2}$$

方程化为

$$\psi'' + k^2\psi = 0$$

通解为
$$\psi(x) = A e^{ikx} + B e^{-ikx}$$

也可表示为三角函数形式：

$$\psi(x) = (A - B)\sin kx + (A + B)\cos kx$$

### $E < V(x)$ 区域
能量本征方程：
$$\psi'' - \frac{2m}{\hbar^2}(V(x) - E)\psi = 0$$

令
$$\rho^2 = \frac{2m(V(x) - E)}{\hbar^2}$$

方程化为

$$\psi'' - \rho^2\psi = 0$$

通解为
$$\psi(x) = C e^{\rho x} + D e^{-\rho x}$$

**反射系数** $R$:

$$R = \frac{(\rho^2 + k^2)^2 \sinh^2(\rho l)}{4\rho^2 k^2 + (\rho^2 + k^2)^2 \sinh^2(\rho l)}$$

**透射系数** $T$:

$$T = \frac{4\rho^2 k^2}{4\rho^2 k^2 + (\rho^2 + k^2)^2 \sinh^2(\rho l)}$$

这个公式是很好记忆的，因为
$$R+T=1$$

所以只需要记住一个就可以了，并且注意到透射系数分子和分母有一项是相同的，即可简单记忆。
## 一维谐振子

势场为
$$V(x) = \frac{1}{2}kx^2$$

能量本征方程：
$$\left[-\frac{\hbar^2}{2m}\frac{d^2}{dx^2} + \frac{1}{2}m\omega^2 x^2\right]\psi(x) = E\psi(x)$$

能量本征值：

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega,\quad E_0 = \frac{1}{2}\hbar\omega \ (\text{零点能})$$

基态波函数为
$$\psi_0(x) = \frac{\sqrt{\alpha}}{\pi^{1/4}}e^{-\frac{\alpha^2 x^2}{2}}$$

第一激发态波函数为
$$\psi_1(x) = \frac{\sqrt{2}\alpha}{\pi^{1/4}}x e^{-\frac{\alpha^2 x^2}{2}}$$

第二激发态波函数为
$$\psi_2(x) = \frac{1}{\pi^{1/4}}\sqrt{\frac{\alpha}{2}}\left(2\alpha^2 x^2 - 1\right)e^{-\frac{\alpha^2 x^2}{2}}$$

一般形式波函数为
$$\psi_n(x) = A_n e^{-\frac{\alpha^2 x^2}{2}}H_n(\alpha x),\quad A_n = \left[\frac{\alpha}{\pi^{1/2} 2^n n!}\right]^{1/2},\quad\alpha=\sqrt{\frac{m\omega}{\hbar}}$$

这时候就有一点没有学的小朋友问了 $H_{n}$ 是个什么东西？$H_{n}$ 是厄密多项式（Hermite polynomials）。
能量本征值：

$$E_n = \left(n + \frac{1}{2}\right)\hbar\omega,\quad E_0 = \frac{1}{2}\hbar\omega \ (\text{零点能})$$

关于一维谐振子的推导，升降算符（创生算符与湮灭算符）是极具启发性的方法。具体内容可参考经典量子力学教材，如台湾大学姚珩老师的《量子力学》、科恩-塔诺季《量子力学》（上卷），以及格里菲思《量子力学导论》。
