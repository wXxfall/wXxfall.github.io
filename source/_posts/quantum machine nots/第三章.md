# 力学量用算符表达

## 对易
对易子定义：

$$[\hat{A},\hat{B}] = \hat{A}\hat{B} - \hat{B}\hat{A}$$

可以这样通俗理解对易关系：如果对同一个粒子的波函数，先测量物理量A、再测量物理量B，与先测量B、再测量A得到的结果完全相同，那么两次测量结果相减为零，对应的A和B算符就是对易的。
## 对易关系汇总
| 对易关系类型 | 表达式 | 编号 |
|-------------|--------|------|
| **基本对易关系** | $[x, p_x] = i\hbar$ | (1) |
| | $[x_i, p_j] = i\hbar\delta_{ij}$ | (2) |
| **角动量对易关系** | $[\hat{l}_i, x_j] = i\hbar x_k \varepsilon_{ijk}$ | (3) |
| | $[\hat{l}_i, \hat{l}_j] = i\hbar \hat{l}_k \varepsilon_{ijk}$ | (4) |
| | $[\hat{l}_i, p_j] = i\hbar p_k \varepsilon_{ijk}$ | (5) |
| | $[\hat{l}^2, \hat{l}_i] = 0$ | (6) |
| | $[\hat{l}, \hat{l}] = 0$ | (7) |

## 厄米算符
定义：
$$\langle \psi | \hat{A} | \psi \rangle = \langle \psi | \hat{A}^\dagger | \psi \rangle$$

性质：
$$\hat{A}^\dagger = \hat{A}$$

等价定义：
$$\hat{A} = \hat{A}^* \ (\text{共轭转置})$$

满足这个关系的算符称为厄米算符。
## 厄米算符的基本定理
### 基本定理
1. 厄米算符的本征值为实数。
2. 厄米算符属于不同本征值的本征函数彼此正交。
**Proof**:
设厄米算符$\hat{A}$ 的本征方程为

$$\hat{A}\psi_n = A_n\psi_n,\quad \hat{A}\psi_m = A_m\psi_m$$

取厄米共轭
$$\hat{A}\psi_m^* = A_m\psi_m^*$$

两边左乘 $\psi_n$ 并积分
$$\int \hat{A}\psi_m^* \cdot \psi_n dx = A_m \int \psi_m^* \psi_n dx$$

即
$$\langle \hat{A}\psi_m | \psi_n \rangle = A_m \langle \psi_m | \psi_n \rangle$$

左边利用厄米算符性质 $\langle \hat{A}\psi_m | \psi_n \rangle = \langle \psi_m | \hat{A}\psi_n \rangle$，代入本征方程
$$\langle \psi_m | \hat{A}\psi_n \rangle = \langle \psi_m | A_n\psi_n \rangle = A_n \langle \psi_m | \psi_n \rangle$$

因此

$$A_m \langle \psi_m | \psi_n \rangle = A_n \langle \psi_m | \psi_n \rangle$$

整理得
$$(A_m - A_n) \langle \psi_m | \psi_n \rangle = 0$$

若$A_m \neq A_n$，则

$$\langle \psi_m | \psi_n \rangle = 0$$

即$\psi_m$ 和 $\psi_n$ 正交。
(Q.E.D)

## 例题1,3(考过) p62

### 例1 角动量z分量 $\hat{l}_z = -i\hbar \frac{\partial}{\partial \varphi}$ 的本征值与本征函数
本征方程：
$$-i\hbar \frac{\partial}{\partial \varphi}\psi = l'_z \psi$$

其解为：
$$\psi(\varphi) = C \exp\left[i l'_z \varphi/\hbar\right]$$

由周期性边界条件$\psi(\varphi+2\pi) = \psi(\varphi)$，得

$$l'_z = m\hbar,\quad m=0,\pm1,\pm2,\dots$$

归一化条件$\int_0^{2\pi} |\psi_m(\varphi)|^2 d\varphi = 2\pi |C|^2 = 1$，取 $C=1/\sqrt{2\pi}$，归一化本征函数为

$$\psi_m(\varphi) = \frac{1}{\sqrt{2\pi}} e^{im\varphi},\quad m=0,\pm1,\pm2,\dots$$

正交归一条件

$$\langle \psi_m | \psi_n \rangle = \delta_{mn}$$

### 例2 动量x分量 $\hat{p}_x = -i\hbar \frac{\partial}{\partial x}$ 的本征函数
本征方程：
$$-i\hbar \frac{\partial}{\partial x}\psi = p'_x \psi$$

解为

$$\psi_{p'_x}(x) = C e^{i p'_x x/\hbar}$$

取归一化常数$C=1/\sqrt{2\pi\hbar}$，得

$$\psi_{p'_x}(x) = \frac{1}{\sqrt{2\pi\hbar}} e^{i p'_x x/\hbar}$$

满足δ函数归一化
$$\int_{-\infty}^{+\infty} \psi_{p'_x}^*(x)\psi_{p''_x}(x) dx = \delta(p'_x - p''_x)$$

## 不确定度关系

$$\Delta A \cdot \Delta B \ge \frac{1}{2} \left| \langle [\hat{A},\hat{B}] \rangle \right| = \frac{1}{2} \left| \langle \psi | [\hat{A},\hat{B}] | \psi \rangle \right|$$

## $\hat{l}^2$ 和 $\hat{l}_z$ 的共同本征态（球谐函数）
本征方程：
$$\hat{l}^2 Y_{lm} = l(l+1)\hbar^2 Y_{lm}$$

$$\hat{l}_z Y_{lm} = m\hbar Y_{lm}$$

量子数取值：

$$l=0,1,2,\dots,\quad m=l,l-1,\dots,0,\dots,-l+1,-l$$

正交归一性：

$$\int_0^{2\pi}\int_0^\pi \sin\theta\,d\theta d\varphi\, Y_{lm}^* Y_{l'm'} = \delta_{ll'}\delta_{mm'}$$

$$\langle Y_{lm}|Y_{l'm'} \rangle = \delta_{ll'}\delta_{mm'}$$

球谐函数表达式：

$$Y_{lm}(\theta,\varphi) = (-1)^m \sqrt{\frac{2l+1}{4\pi}\frac{(l-m)!}{(l+m)!}} P_l^m(\cos\theta) e^{im\varphi}$$

其中 $l$ 为轨道角动量量子数，$m$ 为磁量子数；$\hat{l}^2$ 本征值简并，$m$ 有 $2l+1$ 个取值，$Y_{lm}$ 用 $\hat{l}_z$ 区分简并态。
## 对易力学量完全集（C.S.C.O）
定义：一组**相互对易**的厄米算符$\{\hat{A},\hat{B},\dots\}$，其共同本征态由一组**完备量子数** $\alpha$ 标记，给定 $\alpha$ 可唯一确定体系状态，称其为**对易力学量完全集（CSCO）**。
若CSCO 包含体系的Hamilton 量$\hat{H}$，则力学量完全集中的力学量均为**守恒量**，称为**守恒量完全集（CSCCO）**。
## 动量与位置本征函数（δ函数归一化）
动量本征函数：
$$\psi_{p'}(x) = \frac{1}{\sqrt{2\pi\hbar}} e^{i\frac{p'x}{\hbar}}$$

位置本征函数：
$$\psi_{x'}(x) = \delta(x-x')$$

正交归一性：

$$\langle \psi_{p'}|\psi_{p''}\rangle = \delta(p'-p'')$$

$$\langle \psi_{x'}|\psi_{x''}\rangle = \delta(x'-x'')$$

δ函数性质：
$$\int_{-\infty}^\infty f(x)\delta(x-x_0)dx = f(x_0)$$

$$\delta(x-x_0) = \frac{1}{2\pi}\int_{-\infty}^\infty e^{ik(x-x_0)}dk$$
