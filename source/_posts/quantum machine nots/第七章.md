# 自旋（第八章）
## 自旋概率密度
电子自旋向上（$S_z = \hbar/2$）、位置在 $\boldsymbol{r}$ 处的概率密度为：
$$\left| \psi\left(\boldsymbol{r}, \frac{\hbar}{2}\right) \right|^2$$

电子自旋向上的总概率：

$$\int d^3 r \left| \psi\left(\boldsymbol{r}, \frac{\hbar}{2}\right) \right|^2$$

## 自旋波函数自旋波函数为二维列向量：

$$\chi(S_z) = \begin{pmatrix} a \\ b \end{pmatrix}$$

归一化条件：

$$\langle \chi(S_z) | \chi(S_z) \rangle = 1$$

自旋 $S_z$ 的本征态：
 自旋向上（$S_z = \hbar/2$）：

$$\chi_+ = \begin{pmatrix} 1 \\ 0 \end{pmatrix}$$

自旋向下（$S_z = -\hbar/2$）：

$$\chi_- = \begin{pmatrix} 0 \\ 1 \end{pmatrix}$$

体系总波函数（空间-自旋）：

$$\psi(\boldsymbol{r}, S_z) = \psi\left(\boldsymbol{r}, \frac{\hbar}{2}\right) \chi_+ + \psi\left(\boldsymbol{r}, -\frac{\hbar}{2}\right) \chi_-$$

## Pauli矩阵
Pauli矩阵的具体形式：

$$\sigma_x = \begin{pmatrix} 0 & 1 \\ 1 & 0 \end{pmatrix}, \quad
\sigma_y = \begin{pmatrix} 0 & -i \\ i & 0 \end{pmatrix}, \quad
\sigma_z = \begin{pmatrix} 1 & 0 \\ 0 & -1 \end{pmatrix}$$

对易关系：
$$[\sigma_i, \sigma_j] = 2i \varepsilon_{ijk} \sigma_k$$

平方性质：
$$\sigma_x^2 = \sigma_y^2 = \sigma_z^2 = \hat{I}$$

反对易关系：

$$\sigma_i \sigma_j + \sigma_j \sigma_i = 0 \quad (i \neq j)$$

## 自旋-轨道耦合
$\hat{l} \cdot \hat{s}$ 耦合：总角动量算符：

$$\hat{\boldsymbol{j}} = \hat{\boldsymbol{l}} + \hat{\boldsymbol{s}}$$

关键对易关系：
$$[\hat{j}^2, \hat{l} \cdot \hat{s}] = 0, \quad [\hat{j}^2, \hat{j}_z] = 0$$

总角动量平方与轨道、自旋角动量的关系：

$$\hat{j}^2 = \hat{l}^2 + \hat{s}^2 + 2 \hat{\boldsymbol{l}} \cdot \hat{\boldsymbol{s}}$$

本征值方程：

$$\hat{l}^2 \phi = l(l+1)\hbar^2 \phi$$

$$\hat{j}_z \phi = m_j \hbar \phi$$

$$\hat{j}^2 \phi = j(j+1)\hbar^2 \phi$$

量子数取值：$l = 0,1,\dots,n-1$，$j = l \pm \frac{1}{2}$，$m_j = j, j-1, \dots, -j$。
## 双线结构与反常Zeeman效应
考虑自旋-轨道耦合的哈密顿量：

$$\hat{H} = \frac{\hat{p}^2}{2\mu} + V(r) + \xi(r) \hat{\boldsymbol{l}} \cdot \hat{\boldsymbol{s}}$$

能级 $E_{nl}$ 分裂为 $E_{nl(l+1/2)}$ 和 $E_{nl(l-1/2)}$，满足：

$$E_{nl(l+1/2)} > E_{nl(l-1/2)}$$

此外，体系存在**反常Zeeman效应**。
## 二电子自旋
二电子总自旋算符：

$$\hat{\boldsymbol{S}} = \hat{\boldsymbol{s}}_1 + \hat{\boldsymbol{s}}_2$$

对易关系：
$$[\hat{\boldsymbol{s}}_1, \hat{\boldsymbol{s}}_2] = 0, \quad [\hat{S}^2, \hat{S}_z] = 0$$

总自旋平方：

$$\hat{S}^2 = \hat{s}_1^2 + \hat{s}_2^2 + 2 \hat{\boldsymbol{s}}_1 \cdot \hat{\boldsymbol{s}}_2$$

总自旋本征值为 $S(S+1)\hbar^2$，其中 $S=0,1$：
- $S=1$（三重态）：$m_S = 1, 0, -1$
- $S=0$（单态）：$m_S = 0$

## 自旋波函数 $\chi_{S m_S}$
### 三重态
- $S=1, m_S=1$：
  $$\chi_{11} = \alpha(1)\alpha(2)$$

- $S=1, m_S=0$：
  $$\chi_{10} = \frac{1}{\sqrt{2}} \left[\alpha(1)\beta(2) + \beta(1)\alpha(2)\right]$$

- $S=1, m_S=-1$：
  $$\chi_{1,-1} = \beta(1)\beta(2)$$

### 单态
- $S=0, m_S=0$：
  $$\chi_{00} = \frac{1}{\sqrt{2}} \left[\alpha(1)\beta(2) - \beta(1)\alpha(2)\right]$$

## 纠缠态
由两个粒子组成的复合体系的量子态，若能表示为单粒子态的乘积，则称为**可分离态**；若**不能表示为单粒子态的乘积**，则称为**纠缠态**。
