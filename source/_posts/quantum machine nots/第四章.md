# 力学量的平均值与时间演化

力学量平均值：

$$\bar{A}(t) = \langle \psi(t)|\hat{A}|\psi(t)\rangle$$

时间演化公式：
$$\frac{d}{dt}\bar{A}(t) = \frac{1}{i\hbar}\langle [\hat{A},\hat{H}]\rangle + \langle \frac{\partial\hat{A}}{\partial t}\rangle$$

若$\hat{A}$ 不显含$t$（即$\frac{\partial\hat{A}}{\partial t}=0$）：

$$\frac{d}{dt}\bar{A} = \frac{1}{i\hbar}\langle [\hat{A},\hat{H}]\rangle$$

若$[\hat{A},\hat{H}]=0$，则
$$\frac{d}{dt}\bar{A}=0$$

平均值不随时间改变，概率分布也不变。
## 守恒量与好量子数
量子体系的守恒量**不一定取确定值**（状态不一定是其本征态）；若初始时刻体系处于守恒量$\hat{A}$ 的本征态，则体系保持在该本征态，守恒量的量子数称为**好量子数**。
反之，若不处于$\hat{A}$ 的本征态，则以后也不会处于 $\hat{A}$ 的本征态，但平均值和测量概率分布不变。例：动量本征态是平面波，而一般情况为波包。
量子体系的各守恒量**不一定都可以取确定值**。例：中心力场中，角动量$l_x,l_y,l_z$ 不对易。
## 对称性变换与幺正算符
取一线性变换$\hat{Q}$：
$$\psi \to \psi' = \hat{Q}\psi$$

若$[\hat{Q},\hat{H}]=0$，则 $\hat{Q}$ 为体系的对称性变换：

$$\langle \psi'|\psi'\rangle = \langle \hat{Q}\psi|\hat{Q}\psi\rangle = \langle \psi|\hat{Q}^\dagger\hat{Q}\psi\rangle = \langle \psi|\psi\rangle = 1$$

若$\hat{Q}^\dagger\hat{Q}=\hat{I}$ 且$\hat{Q}\hat{Q}^\dagger=\hat{I}$，则称$\hat{Q}$ 为幺正算符。
对连续变换，考虑无穷小变换：

$$\hat{Q} = \hat{I} + i\varepsilon\hat{F},\quad \varepsilon\to0^+$$

$$\hat{Q}^\dagger\hat{Q} = (\hat{I}-i\varepsilon\hat{F}^\dagger)(\hat{I}+i\varepsilon\hat{F}) = \hat{I} + i\varepsilon(\hat{F}-\hat{F}^\dagger) + O(\varepsilon^2) = \hat{I}$$

若$\hat{F}=\hat{F}^\dagger$（即 $\hat{F}$ 为厄米算符），对称性变换要求$[\hat{Q},\hat{H}]=0$，则
$$[\hat{I}+i\varepsilon\hat{F},\hat{H}]=0 \implies [\hat{F},\hat{H}]=0$$

$\hat{F}$ 为体系守恒量，即**一个对称性变换对应一个守恒量**

## P78 eg1,2,3(判断)

### 例1
设体系$H$ 不显含$t$，显然$[H,H]=0$，所以$H$ 为守恒量，即能量守恒。
### 例2
自由粒子$H=\hat{p}^2/2m$。显然，$[\hat{p},H]=0$，所以$\hat{p}$ 为守恒量。还可以证明$[\hat{l},H]=0$，角动量 $l$ 也是守恒量。
### 例3
中心力场中的粒子$H=\hat{p}^2/2m+V(r)$。不难证明，$[\hat{l},p^2]=0$且$[\hat{l},V(r)]=0$，因此$[\hat{l},H]=0$，所以$l$ 为守恒量。但注意$[\hat{p},V(r)]\neq0$，动量$p$ 并不守恒。
## 全同性是一个可观测

### 什么是 $\hat{P}_{ij}$
$\hat{P}_{ij}$ 的作用是交换体系中第 $i$ 个粒子和第$j$ 个粒子的所有量子状态（包括空间坐标、自旋等全部力学量变量），而保持其他粒子的状态不变。
举个简单例子：对于一个包含$N$ 个全同粒子的体系，波函数为$\psi(q_1,q_2,\dots,q_i,\dots,q_j,\dots,q_N)$（其中$q_k$ 表示第$k$ 个粒子的全部量子变量，如 $q_k=(x_k,y_k,z_k,s_{z_k})$，包含空间坐标和自旋 $z$ 分量）。
通俗理解：就是把波函数中第$i$ 个粒子和第$j$ 个粒子的"位置"互换。
## 对称（波函数满足）：

$$\hat{P}_{ij}\psi = \psi \quad (\text{自旋为整数}) \to \text{Bose子}$$

## 反对称（波函数满足）：
$$\hat{P}_{ij}\psi = -\psi \quad (\text{自旋为半整数}) \to \text{Fermi子}$$

Bose子遵循Bose统计，Fermi子遵循Fermi统计。
Bose子：

$$S_z = n\hbar,\ n=0,1,2,\dots \quad (\text{光子、}\pi\text{介子、Higgs子})$$

Fermi子：

$$S_z = \frac{n\hbar}{2},\ n=1,3,5,\dots \quad (\text{电子、质子、中子})$$

## 两个全同粒子体系
设有两个全同粒子$\hat{H}=\hat{h}(q_1)+\hat{h}(q_2)$，波函数为$\varphi_{k_1}(q_1)$和$\varphi_{k_2}(q_2)$，本征值为 $E_1,E_2$。
对Bose子：
- 当$k_1\neq k_2$时：
  $$\psi^S_{k_1k_2} = \frac{1}{\sqrt{2}}\left[\varphi_{k_1}(q_1)\varphi_{k_2}(q_2) + \varphi_{k_2}(q_1)\varphi_{k_1}(q_2)\right] = \frac{1}{\sqrt{2}}(1+\hat{P}_{12})\varphi_{k_1}(q_1)\varphi_{k_2}(q_2)$$

- 当$k_1=k_2=k$时：
  $$\psi^S_{kk} = \varphi_k(q_1)\varphi_k(q_2)$$

对Fermi子（反对称波函数）：
- 当$k_1\neq k_2$ 时：

  $$\psi^A_{k_1k_2} = \frac{1}{\sqrt{2}}\left[\varphi_{k_1}(q_1)\varphi_{k_2}(q_2) - \varphi_{k_1}(q_2)\varphi_{k_2}(q_1)\right]$$

- 当$k_1=k_2$ 时：

  $$\psi^A = 0$$

**泡利不相容原理**：不允许两个全同的Fermi子处于同一个单粒子态。
