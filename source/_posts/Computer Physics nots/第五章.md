# 数值微分与数值积分
## 数值微分
### 向前差商公式
$$f'(x) = \frac{f(x+h) - f(x)}{h} + O(h)$$

误差为$O(h)$，为 $h$ 的量级，称为“一阶精度”。上式也称为数值微分的欧拉法，两阶微商公式：
### 向后差商公式
$$f'(x) = \frac{f(x) - f(x-h)}{h} + O(h)$$

### 中心差商公式
$$f'(x) = \frac{f(x+h) - f(x-h)}{2h} + O(h^2)$$

### 三点微商公式
### 辛普森微分法
利用向前差商得到导数的递推方程：
$$\begin{cases}
  3m_{k-1} = \frac{1}{h}\left[f(x_{k-2}) - f(x_{k-1})\right] \\
  m_k = \frac{1}{2h}\left[f(x_{k+1}) - f(x_{k-1})\right] \\
  m_{k+1} = \frac{1}{h}\left[f(x_{k+1}) - f(x_k)\right]
\end{cases}$$

$$\implies m_{k-1} + 4m_k + m_{k+1} = \frac{3}{h}\left[f(x_{k+1}) - f(x_{k-1})\right],\ k=1,2,\dots,n-1$$

## 数值积分★

### Newton-Cotes 数值积分公式
思路：将被积函数 $f(x)$ 用$n$ 次拉格朗日插值多项式近似：
$$f(x) \approx L_n(x) = \sum_{i=0}^{n} l_i(x) f(x_i),\quad l_i(x) = \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j}$$

用$L_n(x)$ 近似代替被积函数：
$$I_n(f) = \int_a^b L_n(x) dx = \int_a^b \sum_{i=0}^{n} l_i(x) f(x_i) dx$$

$$= f(x_i) \int_a^b \sum_{i=0}^{n} l_i(x) dx = \sum_{i=0}^{n} f(x_i) \int_a^b l_i(x) dx$$

$$= \sum_{i=0}^{n} f(x_i) \omega_i$$

其中

$$\omega_i = \int_a^b l_i(x) dx = \int_a^b \prod_{\substack{j=0 \\ j \neq i}}^{n} \frac{x - x_j}{x_i - x_j} dx$$

- **梯形积分公式**：$n=1$ 时的 Newton-Cotes 公式：
$$\omega_0 = \int_a^b \frac{x-b}{a-b} dx = \frac{1}{2}h,\quad \omega_1 = \int_a^b \frac{x-a}{b-a} dx = \frac{1}{2}h$$

$$I_1(f) = \frac{h}{2} \left( f(a) + f(b) \right)$$

- **辛普森积分公式**：$n=2$ 时的 Newton-Cotes 公式：
$$\omega_0 = \frac{1}{3}h,\quad \omega_1 = \frac{4}{3}h,\quad \omega_2 = \frac{1}{3}h$$

$$I_2(f) = \frac{h}{3} \left[ f(a) + 4f\left(\frac{a+b}{2}\right) + f(b) \right],\quad h = \frac{b-a}{2}$$

辛普森公式的几何意义为函数$f(x)$ 曲线下抛物线围成的面积。
- **科特斯积分公式**：$n=4$ 时的 Cotes 积分公式：
$$I_4 = \frac{2h}{45} \left[ 7f(a) + 32f(a+h) + 12f(a+2h) + 32f(a+3h) + 7f(b) \right]$$

### 例题 4.2.1（记！）（必考！）证明梯形公式的余项为：
$$R_1 = -\frac{h^3}{12} f''(\xi),\quad \xi \in (a,b),\ h = b-a$$

**Proof**:

$$I_1(f) = \frac{h}{2} \left[ f(a) + f(b) \right]$$

将$f(b)$ 在$a$ 点作泰勒展开：
$$I_1 = \frac{h}{2} \left[ f(a) + f(a) + hf'(a) + \frac{h^2}{2}f''(a) + \dots \right]$$

$$= hf(a) + \frac{h^2}{2}f'(a) + \frac{h^3}{4}f''(a)$$

令$I(x) = \int_a^x f(t) dt$，对 $a$ 点作 $I(b)$ 的泰勒展开：
$$I(b) = hf(a) + \frac{h^2}{2}f'(a) + \frac{h^3}{6}f''(a) + \dots$$

$$R_1 = I(b) - I_1 = -\frac{h^3}{12} f''(\xi),\ \xi \in (a,b),\ h = b-a$$

Q.E.D

### 复化求积公式
当积分区间较大时，将区间分为 $n$ 个子区间（$h = \frac{b-a}{n}$），在每个子区间上应用低阶求积公式，然后求和。
- **复化梯形公式**：将$[a,b]$ 等分为$n$ 个子区间，每个子区间长度 $h = \frac{b-a}{n}$，取等距节点：
$$x_k = a + kh,\quad k=0,1,\dots,n$$

在子区间 $[x_k, x_{k+1}]$ 上使用梯形公式进行积分：

$$\int_{x_k}^{x_{k+1}} f(x) dx = \frac{h}{2} \left[ f(x_k) + f(x_{k+1}) \right]$$

则：

$$\int_a^b f(x) dx = \sum_{k=0}^{n-1} \int_{x_k}^{x_{k+1}} f(x) dx = \sum_{k=0}^{n-1} \frac{h}{2} \left[ f(x_k) + f(x_{k+1}) \right]$$

$$= \frac{h}{2} \left( f(a) + f(b) + 2 \sum_{k=1}^{n-1} f(x_k) \right)$$

- **复化辛普森公式**：将区间分为 $2n$ 个子区间，长度为 $h = \frac{b-a}{2n}$，取等距节点：
$$x_k = a + kh,\quad k=0,1,\dots,2n$$

定义 $k=2m,m=0,1,\dots,n-1$，在区间 $[x_{2m}, x_{2m+2}]$ 上使用辛普森求积公式：
$$\int_{x_{2m}}^{x_{2m+2}} f(x) dx \approx \frac{h}{3} \left[ f(x_{2m}) + 4f(x_{2m+1}) + f(x_{2m+2}) \right]$$

在区间$[a,b]$ 上求积分的近似值：

$$\int_a^b f(x) dx \approx S_{2n} = \sum_{m=0}^{n-1} \int_{x_{2m}}^{x_{2m+2}} f(x) dx$$

$$= \sum_{m=0}^{n-1} \frac{h}{3} \left[ f(x_{2m}) + 4f(x_{2m+1}) + f(x_{2m+2}) \right]$$

$$= \frac{h}{3} \sum_{m=0}^{n-1} \left[ f(x_{2m}) + 4f(x_{2m+1}) + f(x_{2m+2}) \right]$$

$$= \frac{h}{3} \left[ f(a) + f(b) + 2\sum_{m=1}^{n-1} f(x_{2m}) + 4\sum_{m=0}^{n-1} f(x_{2m+1}) \right]$$

- **变步长积分公式**：将区间二等分，在子区间上：

$$T_n = \frac{h}{2} \left[ f(a) + f(b) + 2\sum_{k=1}^{n-1} f(x_k) \right]$$

$$\int_{x_k}^{x_{k+1}} f(x) dx \approx \frac{h}{2} \left[ f(x_k) + f(x_{k+1}) \right]$$

$$= \frac{1}{2} \frac{h}{2} \left[ f(x_k) + f(x_{k+1}) \right] + \frac{1}{2} \frac{h}{2} \left[ f(x_k) + f(x_k) \right]$$

$$= \frac{h}{4} \left[ f(x_k) + f(x_{k+1}) + 2f(x_{k+\frac{1}{2}}) \right]$$

则：

$$T_{2n} = \sum_{k=0}^{n-1} \int_{x_k}^{x_{k+1}} f(x) dx$$

$$= \frac{h}{4} \sum_{k=0}^{n-1} \left[ f(x_k) + f(x_{k+1}) + 2f(x_{k+\frac{1}{2}}) \right]$$

$$= \frac{h}{4} \left[ f(a) + f(b) + 2\sum_{k=1}^{n-1} f(x_k) + 2\sum_{k=0}^{n-1} f(x_{k+\frac{1}{2}}) \right]$$

$$= \frac{1}{2} T_n + \frac{h}{2} \sum_{k=0}^{n-1} f\left(x_k + \frac{h}{2}\right)$$

- **龙贝格积分公式**
龙贝格算法就是逐次分半加速法，它是在复化梯形公式的误差估计的基础上，用线性外推的方法构造的一种加速算法。将积分区间分为$n$ 等份和$2n$ 等份时，得到的误差估计公式：

$$I = T_{2n} + \frac{1}{3}(T_{2n} - T_n)$$

### 例题 4.7
计算积分 $$I = \int_0^1 \frac{4}{1+x} dx$$

1) 将$[0,1]$ 分成 4 等份，用梯形求积公式和辛普森求积公式计算
2) 采用辛普森（$\frac{3}{8}$）公式
**解**
1）将区间 $[0,1]$ 分成 4 等份，子区间长度 $h = \frac{b-a}{4} = \frac{1}{4}$，节点$x_i = 0 + ih = \frac{i}{4}$，在区间上应用梯形积分公式：
$$\int_{x_i}^{x_{i+1}} f(x) dx = \frac{h}{2} \left[ f(x_i) + f(x_{i+1}) \right]$$

对每个区间求和得：
$$\int_a^b f(x) dx = \frac{h}{2} \left[ f(a) + f(b) + 2\sum_{k=1}^{n-1} f(x_k) \right]$$

$$\int_0^1 \frac{4}{1+x^2} dx = \frac{1}{8} \left[ 4 + 2 + 2 \left( \frac{4}{1+\frac{1}{4}^2} + \frac{4}{1+\frac{1}{2}^2} + \frac{4}{1+\frac{3}{4}^2} \right) \right]$$

$$\approx \frac{1}{8} \left[ 6 + 2 \left( \frac{4}{\frac{17}{16}} + \frac{4}{\frac{5}{4}} + \frac{4}{\frac{25}{16}} \right) \right] = \frac{1}{8} \left[ 6 + 2 \left( \frac{64}{17} + \frac{16}{5} + \frac{64}{25} \right) \right] = \frac{10646}{3400}$$

将区间$[0,1]$ 分成 4 等份，子区间长度 $h = \frac{b-a}{4} = \frac{1}{4}$，节点$x_i = 0 + ih = \frac{i}{4}$，在区间上应用辛普森积分公式：

$$\int_{x_{2m}}^{x_{2m+2}} f(x) dx \approx \frac{h}{3} \left[ f(x_{2m}) + 4f(x_{2m+1}) + f(x_{2m+2}) \right]$$

求和得到：
$$\int_{x_i}^{x_{i+1}} f(x) dx=\frac{h}{3} \left[ f(a) + f(b) + 2\sum_{m=1}^{n-1} f(x_{2m}) + 4\sum_{m=0}^{n-1} f(x_{2m+1}) \right]$$

$$\int_0^1 \frac{4}{1+x^2} dx = \frac{1}{12} \left[ 4+2+2(\frac{16}{5})+4(\frac{64}{17}+\frac{64}{25})\right] = \frac{16022}{5100}$$

2) $\frac{3}{8}$辛普森积分公式：

$$\int_a^b f(x) dx = \frac{b-a}{8} \left[ f(a) + 3f\left(a+\frac{b-a}{3}\right) + 3f\left(a+\frac{2(b-a)}{3}\right) + f(b) \right]$$

代入 $a=0,b=1$ 得：
$$\int_0^1 \frac{x}{1+x} dx = \frac{1}{8} \left[ f(0) + 3f\left(\frac{1}{3}\right) + 3f\left(\frac{2}{3}\right) + f(1) \right]$$

代入函数值$f(\frac{1}{3})=\frac{1}{4},\ f(\frac{2}{3})=\frac{2}{5}$ 得：
$$= \frac{1}{8}\left[ 0 + 3\cdot\frac{1}{4} + 3\cdot\frac{2}{5} + \frac{1}{2} \right] = \frac{1}{8}\left( \frac{3}{4}+\frac{6}{5}+\frac{1}{2} \right) = \frac{1}{8}\cdot\frac{15+24+10}{20} = \frac{49}{160}$$

### eg4.8
求积分$$I = \int_0^1 \frac{dx}{1+x}$$，用梯形和 $n=4$ 复化梯形公式计算

**解**

a) 将区间$[0,1]$ 上应用梯形积分公式：

$$\int_a^b f(x) dx = \int_0^1 \frac{dx}{1+x} = \frac{1-0}{2} \left[ f(0) + f(1) \right] = \frac{1}{2} \left( 1 + \frac{1}{2} \right) = \frac{3}{4}$$

b) 将区间$[0,1]$ 分成 4 等份，子区间长度 $h = \frac{b-a}{4} = \frac{1}{4}$，节点$x_i = 0 + ih = \frac{i}{4}$
在区间上应用梯形积分公式：
$$\int_{x_i}^{x_{i+1}} f(x) dx = \frac{h}{2} \left[ f(x_i) + f(x_{i+1}) \right]$$

对每个区间求和得：
$$\int_a^b f(x) dx = \sum_{i=0}^{n-1} \int_{x_i}^{x_{i+1}} f(x) dx = \frac{h}{2} \sum_{i=0}^{n-1} \left[ f(x_i) + f(x_{i+1}) \right]$$

$$= \frac{h}{2} \left[ f(x_0) + f(x_1) + f(x_1) + f(x_2) + f(x_2) + f(x_3) + f(x_3) + f(x_4) \right]$$

$$= \frac{h}{2} \left[ f(a) + f(b) + 2\sum_{i=1}^{3} f(x_i) \right] = \frac{1}{8} \left( 1 + \frac{1}{2} + \frac{8}{5} + \frac{4}{3} + \frac{8}{7} \right) = \frac{961}{1680}$$
