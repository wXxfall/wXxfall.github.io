# 绪论

## 计算物理定义
计算物理学是以计算机以及计算机技术为工具和手段，运用计算数学的方法，解决复杂物理问题的一门应用科学。计算物理学是计算机科学、数学和物理学三者间新兴的交叉学科。
## 误差相关概念
1. **误差**
误差为准确值与近似值之差：

$$E = z^* - z$$

其中$E$ 为误差，$z^*$ 为准确值，$z$ 为近似值。
2. **误差限**
真实情况中，准确值是未知的。通常，若存在一个小正数 $\varepsilon$，使不等式：

$$|E| = |z^* - z| \le \varepsilon$$

成立，则$arepsilon$ 为近似值$z$ 的误差限，表示准确值在 $[z-\varepsilon, z+\varepsilon]$ 范围内。按四舍五入法得到近似数的绝对误差是其末位的半个单位。
3. **相对误差**
相对误差定义为：

$$E_r = \frac{|E|}{|z^*|} = \frac{|z^* - z|}{|z^*|}$$

相对误差的绝对值上界称为相对误差限 $\varepsilon_{r}$，记为：

$$E_r = \frac{|E|}{|z^*|} \le \frac{\varepsilon}{|z^*|}=\varepsilon_{r} \approx \frac{\varepsilon}{|z|}$$

### 例题：按四舍五入法，$\pi$ 的近似值为 3.14，求 $E_{r}$ 和 $\varepsilon_{r}$
绝对误差限：
$$E = 0.005$$

相对误差限：
$$E_r = \frac{\varepsilon}{|z|} = \frac{0.005}{3.4} \approx 0.147\%$$

4. **有效数字**
- **定义1**: 如果近似值$z$ 的误差限不超过某一位上的半个单位，该位到$z$ 的第一个非零数字，或$z$ 准确到该位。
- **定义2**：设近似值$z$ 表示为$z=0.x_1x_2\cdots x_n \times 10^m$，其中$x_i(i=1,\cdots,n)$ 是*不一定取确定值*的数字。

$$|z^* - z| \le 0.5 \times 10^{m-n}$$

则称 $z$ 为$z^*$ 的$n$ 位有效数字的近似值。
## 误差来源
1. 模型误差（数学模型与实际问题的差异）
2. 观测误差（实验测量误差）
3. 截断误差（近似解法的误差）
4. 舍入误差（数值计算中舍入引起的误差）

## 数值计算应注意的问题
1. 避免相近两数相减
2. 防止大数吃小数
3. 避免小分母溢出
4. 减少运算次数
5. 正交与交替级数的计算
