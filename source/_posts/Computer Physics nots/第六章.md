# 常微分方程（ODE）
## 基本设定
求解区间 $[a,b]$，步长：

$$h = \frac{b-a}{N}$$

节点：
$$t_k = a + kh,\quad k=0,1,\dots,N$$

## 欧拉（Euler）方法
### 差商近似方法
在$t_k$ 处导数$u'(t_k)$ 用向前差商表示为：
$$u'(t_k) \approx \frac{u(t_{k+1}) - u(t_k)}{h}$$

对于微分方程 $u'(t) = f(t,u(t))$，可写为：
$$u(t_{k+1}) - u(t_k) \approx h f(t_k, u(t_k))$$

由初始条件$u_0 = u(t_0)$，可逐步计算得$u_1, u_2, \dots, u_N$，其中$u_k$ 称为 $u(t_k)$ 的近似值。同样也可向后差商得到隐式格式：

$$u(t_{k+1}) \approx \frac{u(t_{k+1}) - u(t_k)}{h}$$

$$\implies u(t_{k+1}) \approx u(t_k) + h f(t_{k+1}, u_{k+1})$$

由于其包含$u_{k+1}$，故为非线性方程组，也称为两步法。
### 积分近似法
对$du = f(t,u)dt$，在区间 $[t_k, t_{k+1}]$ 上积分：

$$u(t_{k+1}) - u(t_k) = \int_{t_k}^{t_{k+1}} f(t,u(t)) dt$$

利用梯形求积公式可得：
$$u(t_{k+1}) \approx u_k + \frac{h}{2}\left[ f(t_{k+1}) + f(t_k) \right]$$

## 欧拉公式的显式和隐式形式

### 预测-校正法
先用显式公式计算，得到一个预测值作为隐式公式的迭代初值，然后用隐式公式迭代一次作为非线性方程的解。
显式欧拉公式：
$$\tilde{u}_{k+1} = u_k + h f(t_k, u_k)$$

隐式（梯形）公式：
$$u_{k+1} = u_k + \frac{h}{2}\left[ f(t_k, u_k) + f(t_{k+1}, \tilde{u}_{k+1}) \right]$$

**注意**：书上推导改进欧拉公式：

$$u_{k+1} = u_k + \frac{h}{2}\left[ f(t_k, u_k) + f(t_{k+1}, u_k + h f(t_k, u_k)) \right]$$

是错的！！，大家做题时务必使用分开的步骤做题，不要用这个。
## 高阶微分方程

高阶微分方程：
$$\begin{cases}
  y^{(n)} = f(x, y, y', \dots, y^{(n-1)}) \\
  y(x_0) = y_0,\ y'(x_0) = y_0',\ \dots,\ y^{(n-1)}(x_0) = y_0^{(n-1)}
\end{cases}$$

思路：可通过引入状态变量$y_1 = y,\ y_2 = y',\ \dots,\ y_n = y^{(n-1)}$，将 $n$ 阶微分方程转化为 $n$ 个一阶微分方程组。
### 边值问题的数值解法
$$\begin{cases}
  y''(x) = f(x, y, y') \\
  \alpha_0 y(a) + \beta_0 y'(a) = \gamma_0 \\
  \alpha_1 y(b) + \beta_1 y'(b) = \gamma_1
\end{cases}$$

- **差分法**：在 $[a,b]$ 上求 $n-1$ 个相等小区间，取：
  $$h = \frac{b-a}{n},\quad x_i = a + (i-1)h,\quad i=1,\dots,n$$

  利用中心差商近似得到二阶微分方程：
  $$y'(x_i) = \frac{y_{i+1} - y_{i-1}}{2h}$$

  $$y''(x_i) = \frac{y_{i+1} - 2y_i + y_{i-1}}{h^2}$$

  代入得到线性方程组：
  $$\frac{y_{i+1} - 2y_i + y_{i-1}}{h^2} = f\left(x_i, y_i, \frac{y_{i+1} - y_{i-1}}{2h}\right)$$

- **打靶法（射击法）**：  将微分方程的边值问题转化为初值问题，转化为对初值问题采用面向的方法求解。
### eg5.2
求解区间$[0,1]$ $y' = x^2 - y^2，y(0)=1$：
**解***：
离散化求解区间$[0,1]$，取 $h=0.1$，a=0。由向前差商：

$$y' = \frac{dy}{dx} \approx \frac{y_{i+1} - y_i}{h} \implies y_{i+1} = y_i + h f(x_i, y_i)$$

在区间$[x_i, x_{i+1}]$ 上：

$$y_{i+1} - y_i = \int_{x_i}^{x_{i+1}} dy = \int_{x_i}^{x_{i+1}} f(x,y) dx$$

利用梯形积分公式，联立得：
$$\tilde{y}_{i+1} = y_i + h f(x_i, y_i)$$

$$y_{i+1} = y_i + \frac{h}{2}\left[ f(x_i, y_i) + f(x_{i+1}, \tilde{y}_{i+1}) \right]$$

由显式公式得到：

$$\begin{cases}
  \tilde{y}_{i+1} = y_i + h f(x_i, y_i) \\
  y_{i+1} = y_i + \frac{h}{2}\left[ f(x_i, y_i) + f(x_{i+1}, \tilde{y}_{i+1}) \right]
\end{cases}$$

### 例题：求解初值问题

$$y_{i+1} = y_i + \frac{h}{2} \left[ f(x_i, y_i) + f(x_{i+1}, \tilde{y}_{i+1}) \right]$$

### 例题：用显式 Euler 方法，梯形方法和预测-校正 Euler 方法写出微分方程

$$\left\{\begin{aligned}&\frac{\mathrm{d}}{\mathrm{d}x}y=-y+x+1, \quad 0<x<1\\&y(0)=1\end{aligned}\right.$$

的迭代公式（取步长$h=0.1$）：
**解**

给定微分方程初值问题：

$$\frac{dy}{dx} = -y + x + 1, \quad 0 < x < 1, \quad y(0)=1,$$

步长 $h=0.1$。记 $f(x,y) = -y + x + 1$，$x_n = nh$，$y_n \approx y(x_n)$。
#### 1. 显式欧拉方法（显式公式）
显式欧拉公式为：

$$y_{n+1} = y_n + h f(x_n, y_n).$$

代入 $f$ 得：
$$y_{n+1} = y_n + 0.1 \cdot (-y_n + x_n + 1) = 0.9 y_n + 0.1 x_n + 0.1.$$

迭代公式为：
$$\boxed{y_{n+1} = 0.9 y_n + 0.1 x_n + 0.1}.$$

#### 2. 梯形方法（隐式公式）
梯形公式为：

$$y_{n+1} = y_n + \frac{h}{2} \left[ f(x_n, y_n) + f(x_{n+1}, y_{n+1}) \right].$$

代入 $f$ 得：
$$y_{n+1} = y_n + \frac{0.1}{2} \left[ (-y_n + x_n + 1) + (-y_{n+1} + x_{n+1} + 1) \right] = y_n + 0.05 \left( -y_n - y_{n+1} + x_n + x_{n+1} + 2 \right).$$

移项整理得：
$$y_{n+1} + 0.05 y_{n+1} = y_n + 0.05(-y_n + x_n + x_{n+1} + 2),$$

$$1.05 y_{n+1} = 0.95 y_n + 0.05(x_n + x_{n+1} + 2).$$

代入 $x_{n+1} = x_n + 0.1$ 得：
$$x_n + x_{n+1} = 2x_n + 0.1,$$

$$1.05 y_{n+1} = 0.95 y_n + 0.05(2x_n + 2.1) = 0.95 y_n + 0.1 x_n + 0.105.$$

于是得：
$$y_{n+1} = \frac{0.95}{1.05} y_n + \frac{0.1}{1.05} x_n + \frac{0.105}{1.05}.$$

化简系数（或保留小数）：

$$\boxed{y_{n+1} = \frac{19}{21} y_n + \frac{2}{21} x_n + 0.1}.$$

#### 3. 预测-校正欧拉方法（改进欧拉方法）
预测步（显式欧拉）：

$$\tilde{y}_{n+1} = y_n + h f(x_n, y_n) = 0.9 y_n + 0.1 x_n + 0.1.$$

校正步（梯形公式，用预测值代替隐式值）：
$$y_{n+1} = y_n + \frac{h}{2} \left[ f(x_n, y_n) + f(x_{n+1}, \tilde{y}_{n+1}) \right].$$

代入 $f$ 得：
$$y_{n+1} = y_n + 0.05 \left[ (-y_n + x_n + 1) + (-\tilde{y}_{n+1} + x_{n+1} + 1) \right].$$

迭代公式（两步形式）为：
$$\boxed{\begin{aligned}
  &\tilde{y}_{n+1} = 0.9 y_n + 0.1 x_n + 0.1,\\
  &y_{n+1} = y_n + 0.05 \left( -y_n + x_n + 1 - \tilde{y}_{n+1} + x_{n+1} + 1 \right).
\end{aligned}}$$

### 例题：求解边值问题
$$( 1) y^{\prime \prime }+ \frac 1xy^{\prime }+ ( 1- \frac 1{x^2}) y= x, 
y( 0) = 0, y( 5) = 1;$$ $$( 2) y^{\prime \prime }+ \sin ( x) y^{\prime }+ \mathrm{e} ^{\tau }y= x^{2}, y( 0) = 0, y( 5) = 3$$

**解**

求解边值问题。采用有限差分法，将区间 $[0,5]$ 等分，步长$h = \frac{5}{N}$，节点$x_i = ih$（$i=0,1,\ldots,N$），记 $y_i \approx y(x_i)$。
#### (1)
方程为：
$$y'' + \frac{1}{x} y' + \left(1 - \frac{1}{x^2}\right) y = x, \quad y(0)=0, \; y(5)=1.$$

用中心差分近似：

$$y''(x_i) \approx \frac{y_{i-1} - 2y_i + y_{i+1}}{h^2}, \quad y'(x_i) \approx \frac{y_{i+1} - y_{i-1}}{2h}.$$

代入方程（$i=1,2,\ldots,N-1$）：

$$\frac{y_{i-1} - 2y_i + y_{i+1}}{h^2} + \frac{1}{x_i} \cdot \frac{y_{i+1} - y_{i-1}}{2h} + \left(1 - \frac{1}{x_i^2}\right) y_i = x_i.$$

乘以 $h^2$ 整理得：
$$y_{i-1} - 2y_i + y_{i+1} + \frac{h}{2x_i} (y_{i+1} - y_{i-1}) + h^2 \left(1 - \frac{1}{x_i^2}\right) y_i = h^2 x_i.$$

合并同类项：

$$\left(1 - \frac{h}{2x_i}\right) y_{i-1} + \left(-2 + h^2 \left(1 - \frac{1}{x_i^2}\right)\right) y_i + \left(1 + \frac{h}{2x_i}\right) y_{i+1} = h^2 x_i.$$

边界条件为：$y_0 = 0$，$y_N = 1$。得到线性方程组为：
$$\boxed{\begin{cases}
  \left(1 - \frac{h}{2x_i}\right) y_{i-1} + \left(-2 + h^2 \left(1 - \frac{1}{x_i^2}\right)\right) y_i + \left(1 + \frac{h}{2x_i}\right) y_{i+1} = h^2 x_i, \quad i=1,2,\ldots,N-1,\\
  y_0 = 0,\\
  y_N = 1.
\end{cases}}$$

#### (2)
方程为：
$$y'' + \sin(x) y' + e^x y = x^2, \quad y(0)=0, \; y(5)=3.$$

中心差分近似代入得：
$$\frac{y_{i-1} - 2y_i + y_{i+1}}{h^2} + \sin(x_i) \cdot \frac{y_{i+1} - y_{i-1}}{2h} + e^{x_i} y_i = x_i^2.$$

乘以 $h^2$ 得：
$$y_{i-1} - 2y_i + y_{i+1} + \frac{h}{2} \sin(x_i) (y_{i+1} - y_{i-1}) + h^2 e^{x_i} y_i = h^2 x_i^2.$$

合并得：
$$\left(1 - \frac{h}{2} \sin(x_i)\right) y_{i-1} + \left(-2 + h^2 e^{x_i}\right) y_i + \left(1 + \frac{h}{2} \sin(x_i)\right) y_{i+1} = h^2 x_i^2.$$

边界条件为：$y_0 = 0$，$y_N = 3$。线性方程组为：
$$\boxed{\begin{cases}
  \left(1 - \frac{h}{2} \sin(x_i)\right) y_{i-1} + \left(-2 + h^2 e^{x_i}\right) y_i + \left(1 + \frac{h}{2} \sin(x_i)\right) y_{i+1} = h^2 x_i^2, \quad i=1,2,\ldots,N-1,\\
  y_0 = 0,\\
  y_N = 3.
\end{cases}}$$
